## 3. Product Goal
The product is an "AI-Powered Agriculture Crop Advisory Assistant". It empowers farmers and agricultural enthusiasts to input soil metrics (N, P, K, pH), weather conditions, and region data to receive highly specific, AI-generated crop recommendations, fertilizer schedules, and disease diagnoses (via image uploads).

## 4. Mandatory Features
1. **Crop Recommendation Engine:** AI analyzes soil (N, P, K, pH) and climate data to suggest the top 3 optimal crops.
2. **Crop Disease Scanner:** Users can upload images of diseased plant leaves for AI-driven diagnosis and treatment plans.
3. **Advisory History (Dashboard):** All AI recommendations and scan results are saved to a PostgreSQL database and viewable in a dashboard.
4. **Export to PDF:** Ability to export the AI's detailed advisory report.
5. **Responsive Design:** Mobile-first layout for farmers in the field.

## 6. Application Pages (Routes)

3. **`/scanner` (Disease Scanner):** Drag-and-drop interface for uploading plant images.
4. **`/dashboard` (History):** Table/Grid view of past advisories and scans, fetched from the PostgreSQL database.

## 7. User Flow
1. User lands on the Home page and navigates to the Advisory or Scanner.
2. User enters parameters (e.g., Nitrogen: 80, Phosphorus: 40, Potassium: 40, pH: 6.5, Rainfall: 200mm, City: Pune).
3. Frontend validates via Zod and sends a POST request to the Express backend.
4. Express backend validates payload, constructs the Gemini prompt, and calls the `@google/genai` SDK.
5. Gemini returns a structured JSON response.
6. Backend saves the response to Replit Postgres.
7. Frontend displays the structured results in a polished UI card.
